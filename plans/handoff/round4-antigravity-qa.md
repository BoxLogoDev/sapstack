## 검증 1 — 로컬 endpoint 무검증 온보딩 (예측: 미기동 서버도 "완료"로 통과)

1. llama-server 프로세스가 없는 상태 확인 (`tasklist | findstr llama-server` → 없어야 함)
2. 앱 데이터 초기화 후 첫 실행 (온보딩이 다시 나오게) — 앱 데이터 위치를 모르면
   앱 실행 후 온보딩이 안 나오는 상태 그대로 Settings → AI 에서 Local 재설정 경로로 대체
3. Provider 선택에서 **Local Model** → endpoint 기본값 그대로 제출
4. 관찰: 검증 에러 없이 다음 단계로 넘어가는가? (예측: 넘어간다)
5. 온보딩 완료 후 채팅 1턴 전송 → 어떤 에러가 언제(즉시/타임아웃) 어떤 문구로 뜨는지 기록

## 검증 2 — Git Bash 게이트 Back 버튼 (예측: 클릭해도 무반응)

1. Git Bash 경고 화면이 뜨는 조건을 만들 수 있으면(Git 미설치 환경이 아니라면 재현 불가 —
   그 경우 "재현 불가(Git 설치됨)" 로만 기록하고 넘어갈 것)
2. 화면의 Back/뒤로 버튼 클릭 → 아무 일도 안 일어나는지 기록

## 검증 3 — 골든패스 → 채팅 프리필 UX

1. 홈(세션 미선택)에서 증상 자유 입력 → 진단 시작
2. 관찰: 새 세션으로 이동 후 **입력창에 텍스트가 채워질 뿐 전송은 안 되는** 것이 맞는지
3. 운영자 관점 한 줄 평가: 자동 전송이 나은가, 프리필 확인 후 수동 전송이 나은가 (근거 포함)

## 리포트 형식

각 검증마다: 재현 절차(실제 수행한 대로) / 관찰 결과 / 예측과 일치 여부 / 스크린샷 없이 텍스트만.
