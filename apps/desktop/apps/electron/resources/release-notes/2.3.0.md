## 새 기능

- **다국어 퀵가이드 완성** — 5개 모듈 → 24개 전 모듈로 확장, 영어·중국어·일본어·독일어·베트남어 5개 언어 × 24모듈 = 120개 가이드 신규 작성
- **클라우드 모듈 자산 보강** — 신규 4개 클라우드 모듈의 IMG 구성 가이드·Best Practice·T-code 자산 확충
- **MCP 도구 3종 추가** — IMG 노드 키워드 검색, 증상→담당 에이전트 자동 라우팅, SAP Note 단계 조회
- **VS Code 확장** — 자리만 있던 커맨드 5개를 실제 동작으로 구현
