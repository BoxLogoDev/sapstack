## 새 기능

- **CBO 스냅샷 — 우리 회사 커스텀 코드를 질문한다** — 관리자가 수집한 Z/Y 커스텀 소스 스냅샷을 앱이 읽어, "이 프로그램이 뭐 하는 거야?" 같은 질문에 실제 소스를 근거로 답합니다. 전용 에이전트와 `/sap-cbo-explain` 커맨드가 추가됐습니다. 주민번호·카드번호 같은 개인정보는 수집 단계에서 마스킹됩니다
- **무설정 첫 실행(관리자 프로비저닝)** — 설치 폴더나 `~/.sapstack/`에 둔 `provision.yaml` 하나로 LLM 연결·API 키·SAP 환경 프로필·CBO 공유 경로가 자동 설정됩니다. 온보딩 화면과 환경 입력 폼이 뜨지 않습니다
- **로컬 LLM 제로 셋팅** — 연결이 하나도 없고 모델 파일(GGUF)이 발견되면 로컬 연결을 자동으로 만들어 바로 채팅할 수 있습니다. 로컬 모델 컨텍스트가 16K로 늘어 sapstack 지식 주입을 수용합니다
- **CBO 스냅샷 공급 채널** — 공유폴더(UNC)를 기동 시 스캔해 더 새 스냅샷만 가져오고, 설정 → CBO 스냅샷에서 ZIP을 직접 가져올 수도 있습니다
- **현업 모드** — 설정의 외관 토글(또는 프로비저닝 `ui_mode: simple`)로 홈이 질문 중심 카드 3장과 예시 질문 칩으로 단순해지고, 새 세션은 승인 프롬프트 없는 `safe` 권한으로 시작합니다

## 개선

- 온보딩 순서를 환영·LLM 연결 → SAP 환경 순으로 바로잡고, 환경 폼의 업종을 선택 항목으로 바꾸고 응답 언어를 UI 언어로 미리 채웁니다
- 설치 안내 문서가 "SAP 직접 접속 안 함" 대신 실제 3경로(복붙 / ADT 브리지 / CBO 스냅샷)를 설명합니다
