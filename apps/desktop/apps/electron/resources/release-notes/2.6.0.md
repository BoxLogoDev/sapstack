## 새 기능

- **Microsoft 계정 로그인(선택)** — 관리자가 `provision.yaml` 에 `auth:` 블록을 넣은 배포에서는 첫 화면에서 회사 Microsoft 계정으로 로그인해야 앱을 쓸 수 있습니다. 누가 쓸 수 있는지는 IT 가 Entra 그룹으로 정하고, 권한이 없으면 "IT 관리자에게 요청" 안내가 뜹니다. 네트워크가 없어도 마지막 확인 후 14일(관리자 설정)까지는 계속 쓸 수 있습니다. 설정 › **Account** 에서 로그인 계정 확인과 로그아웃(공용 PC)이 가능합니다
- **이 프로그램 수정 요청** — 커스텀(Z/Y) 프로그램 설명을 읽은 뒤 답 아래 버튼을 누르면 질문·설명·오브젝트가 미리 채워진 요청서가 열립니다. 기대 동작과 우선순위를 적어 보내면 LS ITC 의 Azure DevOps 보드에 본인 이름으로 변경 요청서(문서)가 만들어지고, 진행 상태는 설정 › **변경 요청** 에서 봅니다. SAP 은 바뀌지 않으며 개발자가 검토합니다. 오프라인이면 초안이 PC 에 남아 나중에 다시 보낼 수 있습니다
- **영어 배포** — SAP 환경 언어가 영어면 안내 프롬프트와 커스텀 코드 가이드(`guide.en.md`)가 영어로 조립되고, 커스텀 코드 질문을 영어 표현(custom, in-house, our program)으로도 알아봅니다. 미국식 사회보장번호·EIN·전화번호도 마스킹합니다

## 개선

- 새 세션 헤더에 로그인 사용자(이름·메일)가 작성자로 남습니다
- 배포 킷 스크립트에 `-Language en`(영문 README, `-en` ZIP) 이 추가되고, 해외 법인 예시 프로비저닝 파일이 함께 제공됩니다

세 기능은 모두 관리자 프로비저닝이 있을 때만 켜지며, 기존 설치의 동작은 그대로입니다.
