# PM 진단 카드 (local)

## 우선 진단 경로

- IW21 통보 후 오더 안 생김 → Notification Type 자동오더 설정
- IP30 기한초과 계속 → Maintenance Plan 주기 vs 현실
- IE02 상태 변경 불가 → 상태 다이어그램 허용 전환
- IW65 카운터 역전 → 이전 판독값보다 낮은지
- KO88 보전오더 정산 실패 → 오더 상태·정산규칙
- 예방계획 변경 → IP30 시뮬 먼저
- 마스터 → IE01 설비 · IP01 계획 · IW31 오더
- PM 오더와 PP 오더 혼용 금지

## 핵심 T-code

IE01: 설비 생성
IE02: 설비 변경
IW21: 보전 통보
IW23: 통보 조회
IW31: 보전 오더
IP01: 예방계획
IP10: 스케줄
IP30: 계획 시뮬
KO88: 정산
IW65: 통보/카운터 목록

## 규칙

- 보전비용은 코스트 센터 귀속 확인. 시뮬 없이 IP30 실기 금지
- 금지: 운영 SE16N, 조직/센터 고정값
- 확신 없으면 "확인 필요"
