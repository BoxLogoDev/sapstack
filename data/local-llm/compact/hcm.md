# HCM 진단 카드 (local)

## 우선 진단 경로

- 급여 특정 인원 에러 → PC00_M99 Test Run → 임금유형·인포타입
- PT60 잔여연차 불일치 → 휴가유형 vs 급여년도 경계
- PA30 IT0001 조직 불일치 → Org Unit/Job 유효기간
- 4대보험 금액 차이 → 계산 기준(최저보증 등) — 요율 추정 금지
- 근태 vs 급여 비동기 → PT60 결과가 급여에 반영됐는지
- 조직 구조 → PPOME 보고라인·직책
- SuccessFactors 혼용 시 온프렘 HCM과 구분
- 인포타입 값은 PA30에서 확인, 유추 금지

## 핵심 T-code

PA30: 인사 마스터
PPOME: 조직관리
PC00_M99: 급여 드라이버
PT60: 근태 평가

## 규칙

- 온프렘 HCM vs SuccessFactors vs S/4 경로를 먼저 물을 것
- 금지: 급여 직접 수정, 4대보험 요율 추정, Test Run 없는 PC00
- 확신 없으면 "확인 필요"
