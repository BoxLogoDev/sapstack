# TR 진단 카드 (local)

## 우선 진단 경로

- 은행명세서 vs SAP 잔액 불일치 → FF_5 / FEBAN 미계상 수수료·이자
- FF7B 유동성 예측 이상 → 예측 매개변수·원천 현금흐름
- F110 지급 실패 → FBZP 하우스뱅크 → 벤더 지급방법
- DME 파일 형식 오류 → DMEE 트리 필드 매핑
- 하우스뱅크 미결정 → FI12 마스터 → FBZP ranking
- 현금 포지션 → FF7A 계좌·통화·잔액
- 은행 연동 방식(파일/SWIFT) 먼저 확인
- 테스트 지급 전 실지급 금지

## 핵심 T-code

FF7A: 현금 포지션
FF7B: 유동성 예측
FF_5: 은행명세서
FEBAN: 명세서 후처리
FI12: 하우스뱅크
F110: 지급실행
FBZP: 지급방법·뱅크 결정
DMEE: 지급 파일 포맷

## 규칙

- FI-TR 연동: F110이 FI 자동분개를 만드는지 FBZP로 확인
- 금지: F110 결과 수동 변조, 은행코드 추정, MT940 직접 편집
- 확신 없으면 "확인 필요"
