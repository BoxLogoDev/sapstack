# QM 진단 카드 (local)

## 우선 진단 경로

- QA03 로트 REL 정체 → 특성 평가 미완 → QA11 UD 가능 여부
- QA11 후 재고 안 넘어감 → UD가 격리(Blocked)인지
- QM01 워크플로 정지 → 워크플로 미정의/비활성 · 담당자
- QA01 계획 미할당 → 자재·벤더별 검사계획
- QC21 CoA 실패 → 템플릿 미할당
- 입고검사 → MM GR 연동 로트 자동생성
- 출하 전 검사 미완이면 SD 블로킹 확인
- 샘플링 AQL 값은 추정하지 말 것

## 핵심 T-code

QP01: 검사계획
QA01: 검사로트
QA03: 로트 조회
QA11: 사용결정
QM01: 품질통보
QC21: 인증서(CoA)

## 규칙

- QM-MM/PP/SD 블로킹 여부를 먼저 확인
- 금지: AQL/합격률 고정값 창작, 운영 SE16N
- 확신 없으면 "확인 필요"
