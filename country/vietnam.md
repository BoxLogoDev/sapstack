# CVI VN: 베트남 (Vietnam) 로컬라이제이션

> 초안. VAT · hóa đơn điện tử(NĐ 123/2020) · VAS 가 축이다.
> 한국 에티콜/국세청 캘린더를 번역하지 않는다. 사회보험 요율은 해마다 바뀌어 **확인 필요**.

## 개요

| 항목 | 값 |
|------|-----|
| **CVI 코드** | VN |
| **회계기준** | VAS (Chuẩn mực kế toán Việt Nam). IFRS 병행은 그룹 정책 |
| **회계연도** | 원칙 1월 1일 ~ 12월 31일. 4~3 은 재정부 승인 시 (스텁 기재) |
| **기본 통화** | VND (동, 소수점 없음이 일반) |
| **VAT** | 표준 10% 가 공개 제도. 한시 인하(8% 등)는 연도별 **확인 필요** |
| **전자인보이스** | hóa đơn điện tử — Nghị định 123/2020 |
| **감독** | Tổng cục Thuế (GDT) |

## 1. 회계 기준 & 폐쇄

### 1.1 회계연도
- 기본은 역년. 다른 기간은 당국 승인.
- T-code: **OB29**. 변형 코드 하드코딩 금지.

### 1.2 VAS
- 계정 체계·보고 양식은 재정부 통달에 따름. 통달 번호·시행일을 여기서 단정하지 않음. **확인 필요**.
- SAP 계정과목표는 사용자 제공 CoA 만.

---

## 2. 세무 규정

### 2.1 VAT (thuế GTGT)
공개된 큰 그림:
- 표준 **10%** 가 오랜 기본 세율.
- 0% 는 수출 등. 5% 는 일부 생필품 범주가 법령에 있다.
- 한시 8% 인하(경기 대응)는 **적용 기간이 끝나는 시점이 바뀐다. 현재 유효 여부 확인 필요.**
- SAP **FTXP**. V1=10% 같은 매핑은 예시. 세금절차 `TAXVN` 은 스텁 기재 — 실명 확인 필요.

### 2.2 CIT (thuế TNDN)
- 스텁의 표준 20% 는 흔히 인용되는 일반 세율. 우대 10/17% 는 산업·지역·기간 조건부. **대상 목록 확인 필요**.
- 예납·연정산 마감은 여기에 날짜를 박지 않는다.

### 2.3 PIT
- 누진 구간·가족공제 금액은 재정부 통달이 개정한다. 스텁의 11M VND/월 은 **현행 여부 확인 필요**.
- 거주자/비거주자 구분.

---

## 3. 전자 인보이스 (hóa đơn điện tử)

### 3.1 법령
- **Nghị định 123/2020** — 전자 영수증 체계의 상위 규정으로 현장에서 가장 많이 인용.
- 시행 세부(통달 78 등)와 의무화 일정은 납세자 규모별로 달랐다. 2022 중반 전면화 서술은 스텁에 있음. **신규 사업자 적용일은 확인 필요**.

### 3.2 SAP 연동
- GDT 직접 연결보다 **인증 ISP**(FPT, VNPT, MISA 등 — 스텁 기재) 를 끼는 구축이 흔하다.
- sapstack 은 SAP/ISP 를 호출하지 않는다. 운영자가 거부 코드·XML 을 붙여넣는다.
- T-code 후보: **EDOC_COCKPIT**, **SLG1**. 베트남 전용 T-code 이름은 등록하지 않음.

## 4. 사회보험 (BHXH / BHYT / BHTN)

세 축:
1. BHXH (사회보험)
2. BHYT (의료)
3. BHTN (실업)

스텁에 있던 요율(8/17.5, 1.5/3, 1/1)은 **연도·차등 군에 따라 바뀐다. 현재 유효 요율 확인 필요. 저장소에 고정값으로 쓰지 말 것.**
SAP HCM MOLGA VN. **PA30**, **PC00_M99**.

## 5. 은행 & 결제

- SBV, NAPAS.
- 주요 은행 명칭은 스텁에 있음. 하우스뱅크 ID 금지.
- VND 이체 포맷은 은행/NAPAS 스펙. DMEE **확인 필요**.

---

## 6. 이전가격 · FTA

- 특수관계 거래 보고는 세법상 의무가 있을 수 있다. 문서 양식·기한 **확인 필요**.
- 한-베 FTA(KVFTA) 원산지 증빙은 GTS/수출 문서. 특혜 세율표를 여기 나열하지 않음.

- 한국 투자기업이 많아 한글 필드 언어 + VAS 계정 체계가 동시에 필요하다.

## 10. 자주 묻는 질문 (FAQ)

**Q. 한국 전자세금계산서 매핑을 그대로 쓰나요?**
A. 안 됩니다. GDT + 인증 ISP + NĐ 123 체계입니다.

**Q. VAT 8% 를 기본으로 박아도 되나요?**
A. 한시 인하인지부터 확인하세요. 기본 제도 세율은 10% 로 알려져 있습니다.

**Q. 사회보험 요율을 에이전트 답변에 적어도 되나요?**
A. 사용자가 해당 연도 통달을 주기 전에는 적지 마세요.
