# Decisions

되돌리기 어렵거나 나중에 "왜 이렇게 했더라"가 되는 판단을 기록한다.

## 규칙

- 파일명 `YYYY-MM-DD-slug.md` — 정렬이 곧 시간순
- **상태는 폴더가 말한다**: `active/` = 지금 유효, `superseded/` = 뒤집힘
  - 파일 안에 "현재 유효: O" 같은 필드를 두지 않는다. 반드시 낡는다
  - 뒤집히면 `git mv active/… superseded/…` + 맨 위에 **무엇이 대체했는지 한 줄**
  - superseded 는 편집하지 않는다. 당시 판단의 기록이지 현재 사실이 아니다
- 결정한 그 자리에서 쓴다. 몰아 쓰면 근거를 잃는다

## 형식

`배경 / 결정 / 근거 / 버린 대안 / 뒤집는 조건` — 마지막이 제일 중요하다.
뒤집는 조건이 없는 결정은 영원히 유효한 척한다.

## 무엇을 남기고 무엇을 안 남기나

| 남긴다                                     | 안 남긴다                         |
| ------------------------------------------ | --------------------------------- |
| 보안·결제·데이터 모델처럼 되돌리기 비싼 것 | 리팩터링·네이밍 같은 일상 판단    |
| 대안을 실제로 저울질한 것                  | 유일한 선택지였던 것              |
| 나중에 뒤집힐 수 있는 것                   | 외부가 강제한 것(플랫폼 요구사항) |
